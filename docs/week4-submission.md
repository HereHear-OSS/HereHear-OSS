## 수행 내용

- **필수과제** — `feature/12-music-register`와 `feature/13-saved-page`에서 작업하고 `feat(register): …`, `feat(save): …` 형식으로 커밋한 뒤 `main`을 대상으로 PR을 열었습니다. PR 코멘트에는 모바일 화면, 좋아요 연속 입력, 이슈 템플릿, PR 설명에 관한 수정 요청과 개선 제안을 남겼습니다.
- **선택과제** — 변경 내용과 테스트 방법을 적는 PR 템플릿을 만들고, CODEOWNERS에 경로별 담당자를 지정했습니다. 협업 문서에 `main` 직접 푸시 금지, 승인·CI 기준, `[MUST]`와 `[SHOULD]` 피드백 처리 절차를 정리했습니다.

## 결과 요약

기능 PR 2건과 PR 코멘트 4건을 증빙으로 제출합니다. 협업 파일 4종은 `main`에서 열람할 수 있으며, GitHub는 `main`을 보호된 브랜치로 표시합니다.
