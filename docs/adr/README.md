# Architecture Decision Records

HereHear의 중요한 기술 결정을 기록합니다.

## 작성 방법

1. `0000-template.md`를 복사해 `번호-제목.md`로 저장합니다. (예: `0002-map-provider.md`)
2. 상태를 `제안`으로 두고 PR을 엽니다. 의견이 필요하면 Discussions의 RFC 카테고리에서 먼저 논의합니다.
3. 합의되면 상태를 `승인`으로 바꾸고 병합합니다.
4. 결정이 바뀌면 기존 문서를 지우지 않고 상태를 `대체됨`으로 바꾼 뒤 새 ADR을 씁니다.
