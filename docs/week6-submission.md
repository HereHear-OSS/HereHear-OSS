# HereHear-OSS 6주차 과제 제출

## 과제명

- 필수과제 — 공개 저장소의 OSS 기본 문서 구축
- 선택과제 1 — 라이선스 비교 및 선택 근거
- 선택과제 2 — Inner Source 도입 로드맵

## 수행 내용

- **필수과제** — MIT 라이선스와 Contributor Covenant 행동 강령을 추가했습니다. README에 데모, 기술 스택, 실행 방법과 기여 안내를 넣고, CONTRIBUTING에 개발 환경 설정과 외부 기여 절차를 보강했습니다.
- **선택과제 1** — 주요 OSS 라이선스의 이용 조건과 의무를 비교하고, HereHear-OSS에 MIT를 선택한 근거를 문서화했습니다.
- **선택과제 2** — HereHear를 파일럿 후보로 삼아 준비, 파일럿, 확산, 정착의 단계별 목표와 역할, 성공 지표를 정리했습니다.

## 결과 요약

PR #21을 통해 OSS 기본 문서 4종과 선택과제 문서 2종을 `main`에 반영했습니다. README에서 실행 방법과 기여 절차를 확인하고 관련 문서로 이동할 수 있습니다.
