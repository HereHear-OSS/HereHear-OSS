## 수행 내용

- **필수과제** — 시작하기(Getting Started), 개발 가이드(Development Guide), 문제 해결(Troubleshooting)을 Wiki 문서 주제로 정리했습니다.
- **선택과제 1** — ADR 작성 양식을 마련하고 Supabase를 백엔드로 선택한 이유를 ADR-0001에 기록했습니다. 신규 이슈·토론 안내, 48시간 동안 댓글이 없는 열린 이슈 표시, 최근 7일간의 이슈·PR 요약을 위한 워크플로 초안 3종을 작성했습니다.
- **선택과제 2** — GitHub Discussions를 활성화하고 RFC 증빙으로 토론 #20을 연결했습니다.

## 결과 요약

프로젝트 Wiki와 Discussions #20을 제출합니다. ADR 템플릿과 의사결정 기록 1건, 운영 자동화 초안 3종은 `main`에 있습니다.
